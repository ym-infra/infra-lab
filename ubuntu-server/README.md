# Ubuntu Server Home Lab

## 概要
使わなくなったノートPCにUbuntu Serverをインストールし、
自宅検証サーバーとして構築しました。

## 環境
- OS: Ubuntu Server 26.04.1 LTS
- CPU: Intel Core i7-8565U
- Memory: 16GB
- Storage: SSD 128GB / HDD 1TB

## 構築内容
- Ubuntu Serverのインストール
- Wi-Fi / Netplan設定
- DHCP予約
- SSHによるリモート接続

詳細な構築手順は [setup.md](./setup.md) を参照。
